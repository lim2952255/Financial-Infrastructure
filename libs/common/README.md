# Common Library

`common`은 기관별 Spring Boot 애플리케이션이 함께 사용하는 순수 Java 라이브러리다.
자체 `main` 함수와 서버 포트가 없으므로 별도 JVM으로 실행하지 않는다.

## 포함하는 것

- 기관 업무에 중립적이고 의미가 안정적인 값 객체
- 여러 기관이 같은 의미로 사용하는 작은 기술적 기반

현재는 다음 값 객체만 제공한다.

- `InstitutionId`: `BANK_A`, `BOK`, `KRX` 같은 기관 식별자
- `CurrencyCode`: `KRW`, `USD` 같은 3자리 통화 코드
- `Money`: 금액과 통화의 조합 및 동일 통화 간 기본 연산

## 포함하지 않는 것

- 기관별 Entity, Repository, Service
- 계좌, 주문, 청산, 결제 같은 기관별 업무 규칙
- 공통 데이터베이스 또는 공통 Schema
- 다른 서비스의 내부 코드를 직접 호출하는 기능

공통 모듈은 작게 유지한다. 두 서비스에서 코드 모양이 비슷하다는 이유만으로 공유하지 않고,
업무 의미와 변경 이유까지 같을 때만 공통 코드로 이동한다.
