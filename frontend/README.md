# Financial Infrastructure Lab Frontend

이 디렉터리는 Financial Infrastructure Lab의 Web UI를 위한 경계다.

Frontend는 내부 기관 서비스의 주소나 데이터베이스를 직접 알지 않고 `dashboard-service`만 호출한다.

예정 화면:

- Customer View
- Infrastructure View
- Scenario / Failure Lab
- Reconciliation View
- Traditional / DLT Rail Comparison

Frontend 프레임워크와 실제 애플리케이션 scaffold는 UI 구현 단계에서 추가한다.
